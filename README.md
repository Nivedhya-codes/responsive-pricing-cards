# Responsive Pricing Cards Website

A responsive pricing cards website built using HTML5 and CSS3, featuring three subscription plans: Basic, Pro, and Enterprise. This project focuses on creating a clean, modern user interface with well-structured layouts and visually appealing pricing cards.

## Features
- Three pricing plans: Basic, Pro, and Enterprise.
- Responsive card layout using CSS Grid and Flexbox.
- Modern styling with typography, colours, spacing, borders, and box shadows.
- Hover effects and smooth CSS transitions.
- CSS transforms to highlight the Pro pricing plan.
- Clean and reusable CSS styling.

## Technologies Used
- HTML5
- CSS3

## What I Learned
- Creating layouts using CSS Grid and Flexbox.
- Styling cards with padding, margins, borders, and shadows.
- Using CSS transitions, hover effects, and transforms.
- Improving UI design and organising CSS code.

## Getting Started
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Explore the pricing cards and their visual effects.
